## Scaling to Second Server Without Rework

- nginx upstream api_backend { server api:8080; server 10.0.0.11:8080; } keepalive 32 - add second server IP via env SECOND_SERVER_IP
- docker-compose second server same file but only api service, mysql/redis stay on first server or move to managed RDS/Elasticache
- Tenant connection resolver JSON map tenant_id -> connection string for dedicated DBs
- Secrets scp via WireGuard VPN
- Same deploy pipeline deploys to both servers via SSH
